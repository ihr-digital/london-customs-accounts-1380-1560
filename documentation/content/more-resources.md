# The More menu

Four companion resources, each opening in its own page, plus this documentation.

## Glossary

The commodity glossary: **3,333 headwords** (7,387 including variant forms)
across 22 categories.

- **Search** terms, variant forms, or descriptions.
- **Filter by grouping** to see one commodity family at a time.
- **Grouping Overview** — what each family contains.
- **Temporal Analysis** — how a commodity's appearances are distributed over time.
- **Grouping Relationships** — how families relate to one another.
- Entries carry Getty AAT and Wikidata identifiers, materials, and the
  geographic provenance of the goods where known.

## Customs Officials

The officers who kept these accounts, **1356–1565**.

- **Search all fields** — name, office, port, date.
- Each record cites the source it came from.

## Name Clusters

How the project decides that two spellings are the same person.

- Separate searches for **names**, **forename groups**, and **surnames**.
- A network visualisation of the clusters: nodes are name forms, edges are
  scored similarity.
- Useful for judging whether a person filter in the Table is catching
  everything it should.

## Particular Customs Accounts

The documentary context: which account books survive, for which port and year.

- **Search officials, ports, references**.
- Gives the archival reference for each account.
